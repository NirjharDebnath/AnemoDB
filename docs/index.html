High-Performance C++ Read-Through Cache Server

AnemoDB sits between high-throughput client applications and PostgreSQL. It eliminates redundant query execution, absorbs sudden traffic spikes, and prevents thundering herd catastrophes with single-flight request coalescing.

bash — install in 30 seconds
# 1. Clone repository
$git clone https://github.com/NirjharDebnath/StormyDB.git AnemoDB
$cd AnemoDB

# 2. Build optimized release binary (-O3)
$make

# 3. Optional: Install system-wide to /usr/local/bin
$sudo make install

# 4. Run AnemoDB from anywhere!
$anemo_db

System Architecture & Design

Engineered from scratch using modern C++17, POSIX socket primitives, and lock-free / condition-variable synchronization.

Core Engineering Highlights

Built for concurrent scalability, memory bounded safety, and real-time observability.

⚡

Request Coalescing

Solves the Thundering Herd Problem. If 500 threads miss the cache on the same query simultaneously, exactly 1 leader thread queries PostgreSQL while 499 followers wait and reuse the result.

🎯

Fast-Path O(1) LRU Eviction

Combines an unordered hash map directory with a doubly-linked list. Under memory pressure, tail eviction executes in O(1) while protecting in-progress reservations.

🛡️

Non-Blocking Listener

The accept loop immediately dispatches client descriptors to the worker pool, preventing Slowloris attacks and socket starvation.

🔒

PostgreSQL Read-Only Scope

Two layers of defense-in-depth: query sanitization at the edge and pqxx::read_transaction at the engine level to prevent destructive SQL mutations.

📊

In-Band Telemetry & Dashboard

Send STATS for ANSI terminal reports or STATS_JSON for real-time monitoring via the bundled Flask + Chart.js web dashboard.

🔌

Resilient Connection Pool

Fixed-size thread pool of persistent PostgreSQL connections with fail-fast validation, idle reconnects, and acquisition timeouts.

Framed Protocol Specification

Clients communicate with AnemoDB over TCP using a simple, delimiter-framed protocol terminated by <EOQ>.

Client Request:

SELECT student_id, name FROM students WHERE student_id = 42;
<EOQ>

Server Response:

<EOQ>
